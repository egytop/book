## مهم قبل ما تنشر — افهم حدود الحماية دي

بما إن الموقع **static** (من غير سيرفر)، الحماية اللي ممكن أعملها
مختلفة عن "تسجيل دخول" حقيقي على سيرفر:

- نص الرواية **مشفّر فعليًا** (AES-256) جوه ملف `novel.enc.json`،
  ومش بيتفك إلا في متصفحك بعد ما تكتب الباسورد الصح. حد يفتح الملف
  مباشرة أو يشوف كود الموقع مش هيقدر يقرا حرف واحد من الرواية.
- **بس** حساب جيت هب المجاني بيشترط إن الريبو يبقى **عام (Public)**
  عشان الـ Pages تشتغل. يعني أي حد يقدر يشوف كود الموقع وملف
  الرواية *المشفّر*، بس مش المحتوى نفسه من غيره الباسورد.
- لو حد عبقري قعد يحاول يكسر التشفير بالقوة (brute force) بجهاز قوي
  جدًا، الباسورد ده (٥ كلمات + رقم) بياخد وقت طويل جدًا وغير عملي
  عشان يتخمّن، خصوصًا إن كل محاولة بتاخد وقت أطول من العادي بسبب
  إعدادات التشفير (٢٥٠,٠٠٠ دورة اشتقاق مفتاح). يعني الحماية دي كويسة
  جدًا لمنع أي حد عادي أو محرك بحث من قراءة روايتك قبل النشر، لكنها
  مش بمستوى حماية بنك أو جهة حكومية.
- ضفت كمان `robots.txt` و`noindex` عشان جوجل وموتورات البحث ماتفهرسش
  الموقع أصلاً.

باختصار: ده أفضل حل ممكن على استضافة مجانية زي GitHub Pages، وكويس
جدًا لغرضك (منع أي حد يقرا روايتك قبل ما تجهز للنشر)، بس مش "مستحيل
الاختراق ١٠٠٪" بالمعنى الحرفي.

## الخطوات (نفس أسلوب موقع النتيجة بالظبط)

### ١. اعمل ريبو جديد
على github.com: **+** → **New repository** → اسم زي `hurras-alsotor`
→ **Public** → من غير أي ملفات إضافية → **Create repository**.

### ٢. افتح Codespace
في صفحة الريبو: **Code** (الأخضر) → تبويب **Codespaces** →
**Create codespace on main**.

### ٣. ارفع الملف المضغوط
هبعتلك zip فيه كل حاجة. ارفعه بنفس طريقة الرفع اللي اتعلمتها (زرار
**...** بجانب EXPLORER → **Upload...**، أو لو كبير حاول جوجل درايف
زي المرة اللي فاتت).

### ٤. فك واستبدل وارفع
```
unzip hurras-reader-site.zip
mv repo/* .
mv repo/.gitignore .
rm -rf repo hurras-reader-site.zip
git add .
git commit -m "أول نسخة من قارئ حراس السطور"
git push
```

### ٥. فعّل GitHub Pages
**Settings** → **Pages** → Source: **Deploy from a branch** → Branch:
**main** والمجلد **/docs** → **Save**.

### ٦. الرابط
بعد دقيقة أو اتنين:
`https://USERNAME.github.io/hurras-alsotor/`

## تحديث الباسورد أو نص الرواية بعدين

**الأسهل:** ارجعلي في شات جديد، ابعتلي نسخة الـ docx المحدّثة، وقولّي
تعمل باسورد جديد أو تحدّث المحتوى. هبعتلك ملف واحد بس
(`novel.enc.json`) تستبدل بيه اللي في `docs/data/` وترفعه.

**أو بنفسك** لو عندك بايثون:
```
pip install python-docx cryptography
python3 tools/build_novel.py path/to/الرواية.docx "باسورد جديد"
```
هيولّد `docs/data/novel.enc.json` جديد مباشرة، من غير ما يكتب أي نسخة
صريحة من الرواية على القرص. بعدها `git add . && git commit && git push`
زي العادة. **ملحوظة:** ملف `.gitignore` المرفق بيمنع رفع ملف الـ docx
أو أي JSON صريح بالغلط — سيبه زي ما هو.

## مميزات القراءة

- **الفهرس** (زرار ☰ فوق يمين): كل الفصول مرتبة بالأجزاء، دوس على أي
  فصل تروحله على طول.
- **إعدادات القراءة** (زرار Aa فوق شمال):
  - **الخط**: أميري، القاهرة، عارف رقعة، تجوال، لطيف
  - **الحجم**: زرار + و−
  - **لون النص**: ٤ ألوان جاهزة + منتقي لون حر
  - **خلفية الصفحة**: ورقي (افتراضي) / سيبيا / ليلي
- الإعدادات وآخر فصل قريته بيتحفظوا على جهازك تلقائي (مش بيتبعتوا لأي
  سيرفر).
- تفتح الباسورد مرة واحدة في كل زيارة للموقع؛ لو قفلت المتصفح وفتحته
  تاني هتحتاج تكتبه تاني (ده مقصود، عشان محدش يفتح الموقع من غيرك لو
  الموبايل وقع في إيد حد).
